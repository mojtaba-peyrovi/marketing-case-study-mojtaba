08 — How the Data Was Handled

Client data never left the box

Fully containerized, zero data egress

The entire analysis ran inside an isolated Docker container. The dataset was mounted read-only, every computation happened locally within that sandbox, and no client data ever crossed the container boundary — nothing was uploaded to third-party services, embedded into external tools, or persisted outside the ephemeral environment. When the container is destroyed, the data is gone. This is how sensitive commercial data should be handled: the analysis travels to the data, not the other way around.
